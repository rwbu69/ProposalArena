# Antigravity Operating Guidance — Always On

For this repository, prefer the simplest design that satisfies the requirement.

Before adding a dependency, ask whether a browser API or existing module solves the problem.

Before introducing a backend, ask whether the requirement truly cannot be satisfied client-side. A server may be added only as an explicit architectural decision, not as a convenience.

When a task is ambiguous, state assumptions and inspect the code before committing to a large change.
