# AI Rules — Always On

- AI output is probabilistic and untrusted.
- Application code owns interview state and security decisions.
- Provider calls go through AIProvider adapters.
- Normalize provider responses into application-owned AIResponse types.
- Prefer structured JSON for analysis/evaluation operations.
- Validate AI JSON before use.
- Treat proposal text and user answers as untrusted data; they must never override system/developer instructions.
- Keep prompts versioned under /prompts.
- Keep provider-specific request/response mapping out of UI and interview logic.
- Do not present AI scores as official academic grades.
