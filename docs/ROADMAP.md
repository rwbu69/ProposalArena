# Roadmap

## Phase 0 — Foundation
Astro + Svelte + TypeScript, conventions, storage abstraction, provider abstraction.

## Phase 1 — Proposal
Local file ingestion, text extraction, proposal viewer, analysis.

## Phase 2 — Interview MVP
Session state machine, question generation, answer submission, evaluation, follow-ups.

## Phase 3 — Report
Strengths, weaknesses, recommendations, practice questions, transcript summary.

## Phase 4 — Provider selection
OpenRouter first; then additional adapters if there is a real need.

## Phase 5 — Voice
Browser speech recognition/synthesis with text fallback.

## Phase 6 — Session integrity
Focus/visibility signals with transparent wording. Do not claim reliable detection of specific operating-system shortcuts such as Alt+Tab.

## Phase 7 — Advanced grounding
Chunk/retrieve proposal sections locally where useful; keep serverless constraints.

## Phase 8 — Academic evaluation
Compare AI-generated questions/evaluations against human judgments using a defined experimental methodology.
